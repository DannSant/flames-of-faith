## Traps found in this round

- **`AssetDatabase.ForceReserializeAssets` keeps removed fields in prefabs.** Load and save them instead (`ReserializeDataAssets` does).
- **Item behaviors load by file name** (`behaviorsJson` ids → `Resources/Effects/EffectBehaviors/<id>`). Never rename a behavior file away from its id.
- **`git rm` stages deletions.** A later `git add` of other files plus a commit sweeps them in; check `git diff --cached --stat` before committing.
- **Instantiating a live object** copies serialized fields only. Runtime state set on the original must be copied by hand (split arrows).
- **Spawners can configure a component before its object is active** (before Awake). Anything that loads defaults must load lazily on first use (`DamageSourceBase.EnsureLoaded`).
- **Unity escapes URLs with lowercase hex** (`%2b`).
- **Apps Script web apps answer with a redirect,** and a POST's redirect must be followed with a GET. `BalanceSheetSync.Send` does it by hand.
- **The sheet's open-ended checkbox columns** make spare rows look like FALSE/FALSE rows. Publish skips rows whose first cell is blank.
