## How the work runs
- **One restyler per window** (`Scripts/UI/Style/Editor/*Restyler.cs`, menu `Tools/Flames of Faith/UI Revamp/`).
  - It edits the existing prefab in place (`UpgradeRestyler.EditPrefab`) and can be run again.
  - It snaps the scene instances (`UpgradeRestyler.SnapSceneInstances`).
  - It reuses `CenterWindowLayout` and `UIBuildHelpers`.
- **Plus:** small code changes, a guard test per window (`*StyleTests`), `CLAUDE.md`, and a `todo.md` checklist. Make one commit per window on `main`.
- **Workflow with the Unity Editor closed** (ask the user to close it; batchmode fails if `Temp/UnityLockfile` exists and Unity is running):
  - restyler: `Unity.exe -batchmode -quit -projectPath . -executeMethod Game.UI.Style.Editor.<X>Restyler.Restyle -logFile <scratch>`;
  - tests: `Unity.exe -batchmode -projectPath . -runTests -testPlatform EditMode -testResults <scratch>/r.xml -logFile <scratch>/t.log`;
  - Unity is at `C:/Program Files/Unity/Hub/Editor/6000.2.10f1/Editor/Unity.exe`.
- **When the Editor is open:** compile-check with dotnet on scratch copies of the csproj files (see the memory note "compile-check-without-unity").
- **Visual check:**
  - Write a temporary `Assets/Scripts/Editor/TempUIPreview.cs` that opens UIMain, switches the canvas to Screen Space Camera with a 1920×1080 RenderTexture camera, deactivates the canvas children not of interest, fills sample data, and writes a PNG to the scratchpad. Read the PNG.
  - Delete the script (and its `.meta`) before committing.
  - Call `cam.Render(); Canvas.ForceUpdateCanvases();` **before** showing anything that measures the canvas. In batchmode the canvas isn't sized to the render target until then.
  - `RectMask2D` clipping isn't applied in a static render unless you call `RecalculateClipping()` / `PerformClipping()`.

## Traps found (each cost time)
- **Root layout overrides:** a prefab instance's root anchors, size and position are kept as scene overrides that `RevertPrefabInstance` / `RevertObjectOverride` do **not** remove. Use `UIBuildHelpers.MatchPrefabRootLayout`, and guard it with `SceneInstanceLayout.AssertMatchesPrefab` in the tests.
- **Full reverts:** never full-revert a scene instance. The user hand-tunes overrides in the scenes.
- **Masking:** every graphic inside a scroll view must be **maskable**. The StatRow texts weren't, which is why the earlier scroll attempt failed.
- **Focus tint:** a `UIWindow.focusFrame` fades the window frame to 8% when focus moves away. Restyled windows clear it (`CenterWindowLayout.UseStandardMarker`).
- **Root canvas sorting:** a Canvas's `overrideSorting` must be written through `SerializedObject` (`m_OverrideSorting`) while it is a root in prefab mode.
- **Prefab modified by the Editor:** the user's Editor sometimes leaves a prefab modified just from opening it (re-serialization). If a restyle overwrites that prefab, say so in the commit summary.
- **Effect items:** they live only in the SQLite DB. Never hand-make Effect `.asset` files.
