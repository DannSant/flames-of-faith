## How the work runs
- **One restyler per window** (`Scripts/UI/Style/Editor/*Restyler.cs`, menu `Tools/Flames of Faith/UI Revamp/`, batchmode `Game.UI.Style.Editor.<X>Restyler.Restyle`).
  - It edits the existing prefab in place (`UpgradeRestyler.EditPrefab`).
  - It snaps the scene instances (`UpgradeRestyler.SnapSceneInstances`).
  - It can be re-run.
- **Shared helpers:**
  - `CenterWindowLayout`: windows, titles, stacked buttons, Small buttons, the standard marker.
  - `UIBuildHelpers`: find-or-create, place / stretch, style components, `MatchPrefabRootLayout`, `RevertChildLayoutOverrides`, `RemovePrefabInstances`.
  - `UIRevampTools.RunOnScenes`.
- **Tests:** `SceneInstanceLayout.AssertMatchesPrefab` / `AssertNoChildLayoutOverrides`.
- **Per window:** small code changes, a guard test (`*StyleTests`), `CLAUDE.md`, a `todo.md` checklist, and one commit on `main`.
- **Workflow with the Editor closed** (check first: `Get-Process Unity`; batchmode fails while the Editor holds the project):
  - Unity: `C:/Program Files/Unity/Hub/Editor/6000.2.10f1/Editor/Unity.exe`.
  - Restyler: `Unity.exe -batchmode -quit -projectPath . -executeMethod <Class>.Restyle -logFile <scratch>`.
  - Tests: `Unity.exe -batchmode -projectPath . -runTests -testPlatform EditMode -testResults <scratch>/r.xml -logFile <scratch>/t.log`.
  - Re-run a restyler after its first run: a second run must change nothing beyond float noise.
- **When the Editor is open:** compile-check with dotnet on scratch copies of the csproj files (memory note "compile-check-without-unity").
- **Visual check:**
  - Write a temporary `Assets/Scripts/Editor/TempUIPreview.cs` that:
    - opens the scene;
    - switches the canvas to Screen Space Camera with a 1920×1080 RenderTexture camera (LevelSelector: set the camera's `cullingMask` to UI);
    - hides what's not of interest and fills sample data;
    - writes PNGs to the scratchpad.
  - Read the PNGs, then delete the script and its `.meta` before committing.
  - Call `cam.Render(); Canvas.ForceUpdateCanvases();` and rebuild the layout groups before measuring.

## Traps found (each cost time)
- **Root layout overrides:** scene instances keep their root anchors, size and position as overrides that a revert doesn't remove. Use `MatchPrefabRootLayout`, guarded by `AssertMatchesPrefab`.
- **Revert, then snap:** `PrefabUtility.RevertPropertyOverride` reloads the instance and can drop a snap done earlier in the same pass. Always revert first. `MatchPrefabRootLayout` now records its values (`RecordPrefabInstancePropertyModifications`), so the order no longer bites, but keep it anyway.
- **Children's leftover layout overrides:** a removed layout group leaves its children's anchors and positions as scene overrides; they pinned the wave results title under the window. Use `RevertChildLayoutOverrides`, guarded by `AssertNoChildLayoutOverrides`.
- **Nested prefab instances** (the confirm dialog in PauseMenu and ShopPane): their root layout overrides live in the *outer prefab*. Snap them in `EditPrefab` of that prefab, not in the scene.
- **Full reverts:** never full-revert a scene instance. The user hand-tunes overrides.
- **Persistent calls on instances:** a scene's onClick / onCancel wiring on a prefab instance is stored as `propertyPath: m_OnClick.m_PersistentCalls...` / `value:` pairs. Tests must match that form. Prefer wiring buttons in code (`[SerializeField] Button` plus `AddListener`) and clearing the persistent calls.
- **Sample texts in prefabs:** restylers fill rows with sample text for the Editor. Runtime code must hide *every* optional row before showing the ones that apply: the wave results showed "Corrupted damage taken: 40".
- **Prefab rename vs Animator clips:** clips bind by object path. Renaming `MenuPanel` → `MainMenuPanel` silently stopped the main menu slide. That's one reason the menu now animates in code.
- **Screen Space - Camera canvases** (LevelSelector): children must sit on the canvas plane. The Stats pane was ~8000 units toward the camera and was clipped on screens wider than 2:1.
- **`UIStyleButton` with a LayoutElement** pins the preferred height to the size role. Buttons that grow with their label (event options) must not have a root LayoutElement.
- **Same-named children:** StatsPane has its own child called `InputPrompts`. Find scene objects by their parent, not with a deep name search.
- **Pixel font glyphs:** PIXEARG may lack symbols such as "·". Use plain "-".
- **Masking:** every graphic inside a scroll view must be maskable.
- **Focus tint:** restyled windows clear `UIWindow.focusFrame` (`UseStandardMarker`).
- **Canvas sorting:** a Canvas's `overrideSorting` must be written through `SerializedObject` while it's a prefab root.
- **Prefabs modified by the Editor:** the user's Editor re-serializes prefabs just from opening them. Check `git status` before a restyle and say in the commit what was already dirty.
- **Effect items:** they live only in the SQLite DB. Never hand-make Effect `.asset` files.
