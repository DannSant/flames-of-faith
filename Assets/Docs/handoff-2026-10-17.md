## How this session worked

- **The Unity Editor was closed,** so batchmode was available:
  - tests: `Unity.exe -batchmode -projectPath . -runTests -testPlatform EditMode -testResults <file> -logFile <file>`;
  - Effect SO generation: `-batchmode -quit -executeMethod Game.Database.ScriptableObjectGenerator.GenerateEffectsSO`.
- **Effect renames:** rename the `.asset` and `.meta` files first, then the DB rows, then regenerate. The generator writes `<name>.asset` and never deletes, so a DB-only rename leaves duplicates. `EffectAssetTests` guards this.
- **New assets** (prefab children, materials, shaders, SOs) were written as YAML, each with a generated `.meta`.
